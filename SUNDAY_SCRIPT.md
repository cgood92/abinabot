# 🤖 Abinabot Sunday Review Script (Printable Chorister Guide)

**Songs:**
1. *I Lived in Heaven* (Children's Songbook, p. 4) — Verses 1 & 2
2. *Christmas Bells Are Ringing* (Children's Songbook, p. 54)

**Controls Reminder:**
- **`Spacebar` / `Right Arrow (→)` / Clicker Forward**: Next Step
- **`Left Arrow (←)` / Clicker Back**: Previous Step *(Use anytime if you accidentally click twice!)*
- **`F`**: Fullscreen (hide browser bars before Primary begins)
- **`V`**: Toggle Hands-Free Voice Ear (optional)

> **Important Note for Audio Files:** Once we generate the `audio/clip-*.wav` files, start a tiny local web server in this folder (`python3 -m http.server 8000`) and open `http://localhost:8000` so the browser can play local files through the Robot-izer DSP cleanly!
